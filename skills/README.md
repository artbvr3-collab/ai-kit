# skills/

All my skills, single source of truth. Format: `skills/<name>/SKILL.md`. Tools link to them with symlinks (`SETUP.md`).

- `start` — new project
- `ship` — commit → review → push
- `review` — reviewer checklist and output format
- `audit` — whole-project audit of a self-hosted service: read-only, parallel agents, verified report; per-project rules in the project's `notes/audit.md` (template: `skills/audit/audit-config.md`)
